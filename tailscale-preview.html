Try private file transfer alongside your existing Reason connection. This installer uses a separate folder and does not replace your current setup.

Download Tailscale preview

Windows 10/11 · Requires Tailscale signed in to the same account as the host · Tailscale installation may require Windows approval

01

Connect Tailscale

Install the official Windows app on your laptop and sign in to the same existing account as the host. Keep both computers awake.

02

Run the preview wizard

Extract this ZIP and double-click Run-Preview-Setup.cmd. It installs under %LOCALAPPDATA%\ReasonBridge-Tailscale-Preview. Your existing ReasonBridge folder and pairing remain untouched.

03

Pair and verify

Use the host's separate Tailscale preview controls to create an RB2 code. Enter it only in the local wizard. Ready requires a matching zero-model host status response. Then copy the wizard's one-time Grokbot instruction.

What has been tested

A 10 MiB random binary file was uploaded, echoed without a model, downloaded and verified by SHA256 through the private endpoint on the host. An existing destination file was preserved. The packaged wizard reused its connection and verified status.

This is a same-host test through the Tailscale address. Transfer from a second laptop on another network has not yet been proven. Files are limited to 10 MiB each. Native image generation has a separate host test; automatic Grokbot attachment cards are not verified.

Requests and files use the private Tailscale connection instead of Reason's message channel. Tailscale handles encryption; there is no public host-control endpoint. The host's model permissions and account checks still apply. No API-key fallback, automatic model retry, account-credential copying or new paid model provider is added.
