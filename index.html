Download Windows setup

Windows 10/11 · PowerShell included · No administrator account or Python required

01

Open the setup wizard

Extract the downloaded ZIP, then double-click Run-Setup.cmd. The wizard verifies the helper and downloads the pinned official Reason binary.

02

Pair privately

Keep your host online. Enter the one-time code from your host only into the local wizard. This website never asks for your code or account login.

03

Use Grok Bot locally

The wizard tests a request without calling a model. Once it shows Ready, copy its one-time instruction into Grok Bot. Grok Bot uses your installed local helper.

One helper for tasks and files

Send a prompt, check its actual result, upload an input file or fetch a returned artifact. Native image requests require a separate permission on your host. Model tasks are off until you enable them; each task checks the existing account route and quota.

The connection uses private authenticated peer transport. It supports no API-key or paid-provider fallback. Grok Bot needs a local shell tool; this is not a native MCP plugin.

Keep the host running

The setup link distributes public installation files only. Your host's controls, pairing codes, task history and account credentials remain private. Network reachability still depends on both devices and their firewalls; the wizard reports Ready only after an actual matching response.

The launcher uses a script policy scoped to its own setup process. It does not change the machine's policy, install a service or start at login.
